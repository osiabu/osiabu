## Open source

- **[Nexuscone](https://github.com/Aperintelligence/nexuscone)**: a tamper-evident, append-only audit ledger for Python. SHA-256 hash chain, optional Ed25519 signing, and optional anchoring of the chain head through OpenTimestamps and an RFC 3161 time-stamp authority. Apache 2.0, on [PyPI](https://pypi.org/project/nexuscone/).
- **[NovaBash](https://github.com/Aperintelligence/novabash)**: a local-first vault for API keys and service credentials. Keys are encrypted in the browser with AES-256-GCM, there is no server, and every change is recorded in a hash-chained local audit trail. Apache 2.0. Live at [novabash.pages.dev](https://novabash.pages.dev).
- **[regulated-ai-checklist](https://github.com/Aperintelligence/regulated-ai-checklist)**: a pre-deployment checklist for shipping AI in regulated environments, covering governance, audit, security, data protection, monitoring and incident response.
- **[awesome-ai-governance](https://github.com/Aperintelligence/awesome-ai-governance)**: a curated list of regulations, standards, open-source primitives and tools for building and auditing AI.
